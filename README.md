## About Me

I am a Computer Science student building practical AI engineering systems and autonomous agentic workflows. Rather than building simple prompt wrappers, I focus on connecting LLMs and multi-agent teams (**CrewAI, LangChain, LangGraph, Google ADK**) to backend services, tools, and databases with application-level validation:

- **Multi-Agent Orchestration & Tool Use:** Designing collaborative role-based agents, planner-validator pipelines, and cyclic workflow graphs that decompose complex tasks into deterministic tool calls.
- **Execution Boundaries & Data Grounding:** Rechecking model outputs against database sources of truth, enforcing business policies, and routing sensitive or high-value actions through human-in-the-loop (HITL) approvals.
- **Reusable Agent Harnesses:** Packaging repeatable prompt chains, context rules, and agent skills that work across modern coding and workflow environments.

## Featured Systems & Projects

### 1. [RetailPilot — Agentic AI Shopping Assistant](https://github.com/Mudassar-Khann?tab=repositories)
- **Stack:** Python, FastAPI, Google ADK, Gemini, Next.js, Tailwind CSS, SQLite, Vercel
- **Architecture:** Connects a conversational styling agent to deterministic backend services that own catalog, pricing, and order state.
- **Reliability Controls:** Decomposes user intent into structured execution plans and rechecks product IDs, prices, and inventory against SQLite before returning responses to the UI.

### 2. [Ambient Expense Approval Agent](https://github.com/Mudassar-Khann?tab=repositories)
- **Stack:** Python, Google ADK, Gemini, FastAPI, Pub/Sub, SQLite, pytest
- **Architecture:** Event-driven workflow that consumes expense submissions, runs LLM-based risk checks, and manages approval state.
- **Safety & Governance:** Redacts PII and screens for prompt injection before LLM execution; auto-approves low-value compliant claims by rule while escalating high-value or flagged requests to a human reviewer.

### 3. [Customer Support Policy-Validation Agent](https://github.com/Mudassar-Khann?tab=repositories)
- **Stack:** Python, FastAPI, Workflow Graphs, Gemini, Docker, Postman, pytest
- **Architecture:** Multi-stage support pipeline that classifies inbound queries, routes shipping questions to a specialized agent, and declines out-of-scope requests.
- **Policy Enforcement:** Validates generated replies against shipping rates, return windows, and regional rules before returning responses via authenticated, rate-limited REST endpoints.

### 4. [My Agent Skills — Cross-Agent Harness & Workflow Toolkit](https://github.com/Mudassar-Khann?tab=repositories)
- **Stack:** Context Engineering, Reusable Playbooks, CLI, Claude Code, Cursor, Codex, Windsurf
- **Architecture:** Portable skill system and CLI for distributing structured instructions, prompt templates, validation rules, and workflows across multiple AI coding and agent environments.

### 5. [Cost-Aware LLM Router](https://github.com/Mudassar-Khann?tab=repositories)
- **Stack:** Python, OpenAI-Compatible APIs, OpenRouter
- **Architecture:** Model-routing service that selects LLM providers based on request traits, handles fallback retries on transient errors, and logs token usage and estimated cost per run.
